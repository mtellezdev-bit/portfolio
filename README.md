## 🧩 Proyecto principal

### Administrador de negocio

Aplicación web para administrar información de clientes, personal,
productos y citas mediante operaciones CRUD.

El proyecto tendrá:

- Listado de registros
- Creación de registros
- Edición de registros
- Eliminación de registros
- Búsqueda y filtros
- Validaciones de formularios
- Estados de carga
- Manejo de errores
- Integración con una API REST
- Diseño responsive
